# `prs`

**When:** a Code session's first reply (`preflight` prints the line), and the weekly close

**Command:** `prs FILE` — FILE is the GitHub connector's `list_pull_requests` (state open), saved as it came

**Open pull requests come back to her** (27 Nov 2026, her words: why on earth are these not getting merged? … each of those merges needed to happen for a reason). Every build chat used to end by asking *merge pull request N?* in that chat. When she didn't answer there, nothing asked again; main moved on until seven pull requests, up to two weeks old, no longer merged.

It prints each open one, oldest first, with its age and one recommendation. Each was made because she asked for something, so the default is to bring it in: **merge** when it still merges, **bring it onto main, then merge** when it clashes. Closing one is hers to say, never the default.

Put the printed list on her short list as yes or no questions, in the order given. On her yes: trial-merge it onto main, run the tests, fix any clash on the pull request's own branch (merge main in, never rewrite her history), and merge. A clash that means choosing between two designs is its own ask, one chat.

`prs    none open` is the usual answer.
