# `close`

**When:** the end of every chat — she says *let's end the session*, or plainly that she's done

**Command:** `close --chat URL --title "TITLE"` (a my day chat adds `--date YYYY-MM-DD --sessions page.json …`)

her order, 25 Oct: QA, then the session entry, then the rename. **QA is the objective** (her rule, 25 Oct): outside a window chat, the entry's first line under `what I did` is `· objective: <what it was> — met | partly met | not met, <why>` — the objective set at the open, or the one the chat worked toward when none was set — and work not met names its next step under `still open`. Do each `FIX` in the order printed — run `dayqa` (my day) or fix the entry, write the entry with the session-entry skill, rename the chat — and run it again until it prints `closed`. Only then is the chat done. **A my day chat keeps ▶️ at its dusk close and takes ✔️ the next morning, once she has seen its page** (J8; her yes, 11 Nov 2026): `close` asks for ▶️ that night and ✔️ from the morning on

**A my day chat closes only when its branches have** (her words, 18 Nov 2026: all of the branches for Monday need to write a session entry and close, and that needs to be codified). Pass every page of `list_sessions` (mine) as `--sessions`; the `branches` line names each chat titled `↳MMDD.n` for the day that has no session entry yet or hasn't closed with ☑️. Message each one to write its entry from its own stretches and close, carrying what is still open onto an open ⚡ row or a ⏯️ prompt; then run `close` again. Without `--sessions` it says the list is missing. Monday 16 Nov is why: the GLO2 map branch sat open with no entry, and the day page showed nothing of her hour in it.

**A branch is archived as soon as it closes** (her words, 18 Nov 2026: each branch needs to be archived as it is completed). When a branch's `close` prints `closed`, the my day chat archives it (`archive_session`) on the branch's one line, and a branch that can reach the session tools archives itself; nothing finished waits for the evening sweep.
