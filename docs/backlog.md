# be•do build backlog

Build work for the system lives here, not in the stream. Moved out of the
stream on 4 Oct 2026: 41 open rows under the be•do drive that were build work,
not life, and rode the weekly carry every week. Her own words, the record ids
and every detail are in her copy of this file in Drive (`be•do/code`); this copy
holds no names.

A chat that can't push writes a build idea to its own
`backlog-inbox-YYMMDD-HHMM.md` in the same Drive folder (J15). A Claude Code
session moves those lines here and trashes the files; an item from the inbox is keyed by the day it was
captured and a letter.

Each item keeps its action key (`YYMMDD_HHMM`), so it traces back to the CSV
archives. Status is the row's last status: ⬜ intention · ▫️ potential · ▶️ in
motion. A new build item is added here by pull request, not as a stream row.
When one ships, its line moves to **Done** with the PR that closed it.
